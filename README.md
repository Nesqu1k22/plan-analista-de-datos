# 🎓 Plan Universitario — Analista de Datos

Guía y seguimiento de estudio. Programa completo de formación profesional en análisis de datos, desde matemática básica hasta un capstone empleable.

> **Duración estimada:** 9–10 meses · **Dedicación:** 12–15 h semanales (≈2 h/día, 6 días)
> **Regla de oro:** 30% teoría / 70% práctica. Nunca estudies una herramienta sin un problema que resolver.

---

## 🧭 Mapa general

```
Fundamentos → Excel → Estadística → SQL → Python → Limpieza → EDA
    → Visualización → BI → Negocio → Analítica avanzada → ML
    → Data Engineering → Metodología → Proyectos → Portfolio
```

## 🎯 Objetivo final

Poder recibir un encargo como:

> *"Las ventas bajaron 12% este trimestre. Averiguá por qué."*

Y recorrer todo el proceso:

```
Pregunta empresarial → SQL/Data → Cleaning → EDA → Estadística
  → Segmentación → Visualización → Power BI → Insights
  → Recomendaciones → Decisión empresarial
```

Eso es formación profesional de analista, no una lista de herramientas aprendidas.
