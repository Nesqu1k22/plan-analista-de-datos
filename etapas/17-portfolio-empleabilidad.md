# 🎯 Etapa 17 — Portfolio + empleabilidad

⏱️ **2–4 semanas** · [[../progreso|← Progreso]]

> Tenés el conocimiento y los proyectos. Ahora hay que hacerlos **visibles y contratables**.

---

## 📁 Portfolio

- [ ] Repo de GitHub por proyecto, con README que cuente la **historia**, no el código
- [ ] Cada README: pregunta de negocio → datos → método → hallazgos → recomendación → capturas
- [ ] Dashboards publicados (Power BI Service público / capturas + video corto)
- [ ] Notebooks limpios (sin celdas rotas, sin output de debug)
- [ ] Un sitio índice simple (GitHub Pages) que linkee los 6 proyectos
- [ ] Perfil de GitHub con README propio

### Regla del portfolio
> Un reclutador te dedica **90 segundos**. Si en 90 segundos no entiende qué problema resolviste y qué encontraste, el proyecto no existe.

❌ "Análisis de datos de ventas con Python y pandas"
✅ "Identifiqué que el 23% del churn venía de un solo canal de adquisición — proyecté un ahorro de $2.4M reasignando presupuesto"

---

## 📄 CV

- [ ] 1 página
- [ ] Título claro: **Analista de Datos**
- [ ] Stack visible arriba: SQL · Python · Power BI · Excel · Estadística
- [ ] 3–4 proyectos con **resultado cuantificado**
- [ ] Verbos de impacto, no de tarea ("identifiqué", "reduje", "proyecté" — no "trabajé con")
- [ ] Sin foto de stock, sin barras de "nivel de habilidad"

---

## 💼 LinkedIn

- [ ] Titular: rol + stack + propuesta de valor
- [ ] "Acerca de" en primera persona, 3 párrafos
- [ ] Proyectos destacados con link
- [ ] Posts sobre lo que vas aprendiendo (te expone y te fija el conocimiento)

---

## 🎤 Entrevistas

### Técnicas
- [ ] SQL en vivo — practicá en HackerRank / StrataScratch / DataLemur
- [ ] Caso de negocio ("las ventas cayeron, ¿qué hacés?")
- [ ] Estadística conceptual (p-value, IC, A/B test)
- [ ] Preguntas sobre tus propios proyectos — **conocelos a fondo**

### Comportamentales (método STAR)
- [ ] Un análisis que cambió una decisión
- [ ] Un error que cometiste y cómo lo detectaste
- [ ] Un desacuerdo con un stakeholder
- [ ] Cómo priorizás cuando te piden 5 cosas a la vez
