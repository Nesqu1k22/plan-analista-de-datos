## Cómo usar esta carpeta

- **Un archivo por concepto**, no por sesión. Las sesiones van en [[../bitacora|bitácora]].
- Nombrá los archivos así: `04-sql-window-functions.md`, `03-estadistica-p-value.md` — prefijo de etapa + tema.
- Escribí **con tus palabras**. Copiar y pegar no cuenta como estudiar.
- Si no lo podés explicar en una nota, no lo entendiste todavía.
- Enlazá con `[[wikilinks]]` a la etapa correspondiente.
