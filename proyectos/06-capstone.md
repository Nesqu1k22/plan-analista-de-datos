## 🔧 Componentes

### SQL
Construís las consultas necesarias.

- [ ] Base cargada con esquema relacional correcto (PKs, FKs)
- [ ] Star schema: fact de ventas + dimensiones
- [ ] Vistas para las consultas recurrentes
- [ ] Queries analíticas con window functions y CTEs

### Python
Realizás:

- [ ] **Cleaning** — con reporte de calidad de datos documentado
- [ ] **EDA** — exploración completa y segmentada
- [ ] **Statistical analysis** — tests de hipótesis sobre las diferencias que encontrás
- [ ] **Customer segmentation** — RFM y/o clustering, con clusters nombrados

### Power BI
- [ ] **Dashboard ejecutivo** — la página que ve el director
- [ ] Páginas de detalle: producto, cliente, tienda, tiempo
- [ ] Medidas DAX con time intelligence
- [ ] Drill-through y navegación
