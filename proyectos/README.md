## 📐 Estándar de proyecto terminado

Un proyecto **no está terminado** hasta que tenga:

- [ ] **Pregunta de negocio** escrita al principio
- [ ] Fuente de datos documentada (link, fecha, licencia)
- [ ] Notebook / queries limpias y reproducibles
- [ ] Reporte de calidad de datos y decisiones de limpieza
- [ ] Análisis con validación de resultados
- [ ] Visualizaciones con títulos que son conclusiones
- [ ] **5–10 insights** concretos
- [ ] **Recomendaciones accionables**
- [ ] README que un no-técnico entienda en 90 segundos
- [ ] Repo público en GitHub
