# 📅 Semanas

Plan día por día de cada semana de estudio. Cada semana tiene su nota con ejercicios y su nota de soluciones.

> Las **etapas** dicen *qué* estudiar. Las **semanas** dicen *qué hacer mañana*.

## Cómo funciona

1. El **viernes anterior** (o el domingo) leés la semana que viene.
2. Cada día tenés bloques con tiempo asignado y checkboxes.
3. Los ejercicios están al final de cada nota semanal.
4. Las **soluciones están en una nota aparte** — no las mires antes de intentar.
5. El sábado cerrás: criterio de dominio, [[../progreso]], [[../bitacora]] y `git push`.

## Regla

> Si una semana no la terminaste, **no pases a la siguiente**. Es mejor ir más lento y sólido que rápido y hueco. El plan tiene margen: las etapas dicen "2–3 semanas" por algo.
